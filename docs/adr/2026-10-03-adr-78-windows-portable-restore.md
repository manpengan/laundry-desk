# ADR-78：Windows 加密离机备份与换机恢复

- 日期：2026-10-03
- 状态：实施中；核心格式与维护入口已实现，Windows 原生验收尚未完成
- 范围：活动 V2 Windows 本机发行，不恢复 Cloud 开发部署，不包含打印硬件验收

## 决策

离机副本包含业务数据库与照片，必须使用口令加密。口令仅从交互输入经标准输入传入运行时，禁止进入命令行参数、环境变量、日志或持久配置。明文只可暂存于运行时受保护的本机目录；可移除介质上只写入加密后的文件。不得把未完成的导出标记为成功。

外来归档不得作为管理员 SQL 或 `pg_restore` 的输入。数据库内容采用有上限的 NDJSON：表顺序、列顺序、列类型与序列清单来自受信任的本机迁移后 PostgreSQL catalog。归档的 schema 指纹及迁移摘要须与目标完全一致。每列导出为 PostgreSQL 文本表示或 null，以保留 bigint、bytea、JSON 和换行文本；导入全部使用参数化 INSERT。归档不能提供 SQL、类型转换表达式、函数、触发器或标识符。

导入仅允许名称为 `laundry_restore_<32位十六进制>` 且数据库 comment 与名称一致的独立影子库，禁止向当前业务库原地写入。目标库必须先由受信任的发行迁移创建并验证 ledger。受信任的 FK 在单个事务内延迟检查，以支持既有业务环形引用；提交前检查全部 FK 并恢复原有约束属性。CHECK、唯一性和 NOT NULL 约束始终生效。应用侧变更触发器只在影子库导入期间暂停，提交前恢复。导入失败不得触发当前库切换。

协议版本 1 使用 `LDWXFER1` 头、PBKDF2-HMAC-SHA256（默认 600,000 次，读取上限 5,000,000 次）、16 字节随机盐和 AES-256-GCM。每块明文最多 1 MiB，4 字节随机 nonce 前缀加 64 位块序号；AAD 同时绑定完整头、块序号和块长度。总明文最多 3 GiB，数据库最多 512 MiB，单行最多 16 MiB。拒绝未知协议、错误块长、篡改、截断、附加数据、错误口令和超限声明；不接受压缩归档。完整归档还以 SHA-256 绑定检查与确认，照片逐文件摘要验证。

## 换机权限与外部副作用

目标实例保留其自身运行时密钥、数据库密码和实例身份。旧会话、刷新凭据、顾客会话、Edge 设备、离线授权、主设备租约、待消费认证证明及迁移批准票据失效。恢复前批准的 AI 动作与在途会话不再执行；自动化活动策略暂停，待审批策略保持待审批。

`ai_provider_keys` 与 `notification_provider_settings` 不导出任何行，导入遇到这些表的外来数据也拒绝。AI 总开关关闭，短信配置须在目标重新设置。业务隐私去重所依赖的 HMAC 数据仍随加密业务数据保留。短信 `queued`、`sending`、`retry_wait`、`accepted` 统一改为 `manual_required` 并清理执行租约，保留成本和供应商结果摘要供核对，禁止恢复后自动重发未知结果。

恢复流程必须在排他维护锁下停止柜台写入，先创建本机数据库与照片联合安全点，再验证归档、准备影子库和照片、写入持久维护日志、切换数据库并完成健康检查。失败或断电后的启动需识别日志，恢复安全点或继续明确的完成阶段。不得仅凭旧程序可以启动就声称跨 schema 可回退；跨 schema 联合升级另见 ADR-80。

## 已完成与验证边界

核心模块 `portable-crypto.mjs`、`portable-schema.mjs`、`portable-authority.mjs`、`portable-database.mjs` 已实现格式、验证、权限清理与参数化影子库导入。单元回归覆盖错误口令、篡改、截断、尾随数据、非法 UTF-8、schema 和权限边界；隔离 PostgreSQL 16 合成环境以 72 个迁移、116 张表验证往返（包括一张测试专用表），覆盖 bigint、bytea、自引用 FK、恶意 SQL 形状文本、序列高水位、旧设备授权撤销、配置排除、摘要失败回滚及最终 FK 有效。

文件容器现已接入完整 SHA-256/AEAD 校验与私有临时目录；Windows 维护界面提供加密离机备份、校验与换机恢复，口令通过显式继承的标准输入管道传给固定 Node 入口。新维护动作复用已有 operation lock、`maintenance.json`、联合安全点及数据库 OID 切换机制，5 类中断回归验证失败保持停止并保留恢复记录。已批准的 v1 迁移通过同一维护链只接受 requestId，目标租户及数据库连接由受信任运行时提供。

联合照片索引同时覆盖衣物照片和 `delivery-evidence` 下的配送凭证；归档将后者编码为 `delivery-UUID.ext`，恢复时重新映射到带独立所有权标记的固定子目录，拒绝其他子目录和路径别名。

本机测试已覆盖容器、秘密输入边界、状态机故障注入、照片与维护入口打包。真实 Windows 验收脚本已增加 native launcher 标准输入链的加密导出、校验、错误摘要拒绝、业务变更后恢复、会话/设备失效及目标运行时秘密保留检查，但尚未在 Windows 执行。可移除介质、WinForms 交互和实际换机仍须实机验收。本记录不构成生产准入；真实顾客数据仍受 ADR-71 所述本机生产准入约束。
