# ADR-28：LAN 设备接入与证书诊断

- 日期：2026-08-08
- 状态：**Accepted**
- 决策者：manpengan
- 前序：[ADR-26：局域网只读 Owner Dashboard 与 HTTPS 边界](2026-08-07-adr-26-lan-owner-dashboard.md)
- 影响：本地 HTTPS 设备接入、证书运维与故障诊断

## 背景

ADR-26 已有严格的私网 HTTPS 网关，但第二台手机仍需要操作者手工拼接地址、核对证书并区分
证书不受信任、后端未启动和端口误暴露。直接自动安装根证书、自动选择网卡或打印完整配置
会扩大主机权限并可能泄露路径和凭据。

## 决策

### 1. 接入信息只从已验证配置生成

新增本地 `onboard` 工具，在网关配置和 X.509 校验通过后，只输出：

- 固定 `/owner` HTTPS 地址及终端二维码；
- 证书 SHA-256 指纹、有效期和 IP SAN 匹配摘要；
- iOS、Android 与 macOS 的人工证书安装/信任步骤。

工具不生成、复制或安装证书，不自动选择网卡，不输出证书/私钥路径、私钥内容、密码、会话、
Cookie、令牌或 PIN。二维码只编码已校验的 Owner URL。

### 2. 证书和连接诊断失败关闭

证书检查必须验证普通文件、无符号链接、私钥权限、证书有效期、目标私网 IPv4 SAN 与证书/
私钥匹配。诊断工具执行有界检查：配置、证书、回环 Server、受信任 HTTPS `/owner` 与
`/health`，以及 PostgreSQL/Fastify 未在 LAN 地址暴露。

诊断结果只使用稳定检查码、布尔值与必要的非敏感摘要；不得回显响应体、异常对象、请求头、
Cookie、凭据或本地密钥路径。失败返回非零状态。

### 3. 不扩大网关能力

接入与诊断不新增代理路由。网关继续只允许 ADR-26 的静态 Owner 页面、认证和通用只读查询；
所有命令、任意上游 URL、Forwarded/X-Forwarded 与根柜台页面继续拒绝。PostgreSQL 与 Fastify
继续只绑定回环地址。

### 4. 验收

- 证书过期、SAN 不匹配、key 不匹配、宽权限、符号链接和非私网 Origin 均失败关闭；
- 二维码内容精确等于校验后的 `/owner` URL，输出快照不包含敏感字段或本地路径；
- 真实网关完成第二设备接入、受信任 HTTPS 健康检查，并证明 LAN 地址无法直连 8787/8543；
- 固定代理面、请求/响应大小、超时、安全头与错误响应继续有回归测试。

## 后果

- ADR-26 的 HTTPS 和聚合 IP 限速取舍不变；本 ADR 只降低人工接入与排障成本。
- 自签/私有 CA 证书验收仍不是正式公网 PKI、互联网发布或 MDM 自动下发。
- 运维文档必须明确证书安装由操作者在设备系统设置中完成。

## 否决的备选

- **自动安装根证书或修改系统钥匙串**：需要额外主机权限且不利于审计，否决。
- **自动监听 0.0.0.0 或自动猜网卡**：可能暴露错误接口，否决。
- **把完整配置/异常写入二维码或诊断日志**：可能泄露本地路径和秘密，否决。
- **为诊断临时开放 Fastify/PostgreSQL**：扩大攻击面且无必要，否决。
