# ADR-79：Windows 自动备份、留存与影子恢复演练

- 日期：2026-10-03
- 状态：实现中，原生 Windows 验收待完成
- 范围：ADR-72 A3；仅活动 V2 本机运行时

自动备份默认关闭，由维护入口配置每日时间、保留份数与天数、剩余空间阈值和恢复演练间隔。配置与最近 50 次运行结果保存在当前用户受保护目录。只记录时间、固定状态码、备份标识和演练结果，不记录原始异常、口令或业务数据。

启用后创建固定名称 `LaundryDeskV2AutomaticBackup` 的当前用户计划任务。任务只运行摘要绑定的发行入口和固定 `scheduled-backup` 动作，普通权限、交互用户登录、每日触发、错过后补跑、禁止并发、禁止强行终止。电脑关机或用户未登录时不承诺执行；维护界面显示逾期提醒。配置保存或任务注册失败时保持关闭，未知同名任务及不符合身份/权限/参数约束的任务拒绝接管。

自动执行与手工维护共用内核排他锁。先检查可用空间并记录开始，再按已有流程停止写入、保存数据库与两域照片联合备份、验证并恢复原运行状态。失败记录有限错误码，维护中断保留已有恢复日志，不自动绕过。界面提供配置、立即执行、失败/空间/逾期提醒，以及最近结果。

按份数与天数清理已经完整验证的本实例备份。始终保留最新两份；当前维护 target/safety 和跨 schema 升降级历史引用的前后数据快照受保护。清理前写入独立的摘要绑定日志，逐个验证并删除固定库存；中断后只继续删除剩余受绑定内容，未知文件、硬链接或重解析路径阻止清理，不递归删除任意目录。

恢复演练读取完整备份并验证照片，创建带 OID 身份的影子库，以发行版本校验迁移 ledger、关键表与照片引用，然后删除影子库。绝不交换当前业务库。失败使用现有维护恢复路径，只处理日志绑定的候选库。演练结果与备份结果共同记录。

本次没有新增业务 Command/Query 或开放端口。新增的维护动作是 `backup-schedule`、`backup-health`、`scheduled-backup`、`backup-drill`，配置只从严格标准输入协议传递。平台仍是 development_only，真实数据准入与 Cloud 暂停约束不变。
