# ADR-88 Windows 电子秤读取与收衣记录

- 状态：软件实现、独立审查、定向回归与 Windows 串口发现通过；硬件验收待实物
- 日期：2026-10-03
- 范围：ADR-72 B7；打印口、钱箱继续暂缓

Windows 主进程只允许列出 COM1–COM256、读取选定串口；通过固定系统 PowerShell/.NET SerialPort
读取 ASCII，支持显式选择波特率与 7E1/7O1/8N1。不允许 renderer 指定路径、脚本、原始写入或系统命令。
读取限时 2.5 秒，子进程总期限 7 秒，串口缓冲最多 4096 字符，单并发且每秒最多一次。
默认不置 DTR/RTS，不发送设备命令。硬件须配置连续输出，串口参数与设备一致。

协议依据 A&D 官方 [HV/HW-G 数据格式](https://www.aandd.jp/products/manual/balances/hvw-g.pdf)
与 [AD-4329A 数据格式](https://www.aandd.jp/products/manual/indicators/ad4329aex.pdf)。只接受 ST 稳定
重量、可选 GS/NT，单位 g/kg，正值整克 1–1,000,000；拒绝不稳定、溢出、皮重、负值、小于克精度、
未知单位与不完整帧。最后一帧不稳定时不能复用旧稳定值。该适配不声称兼容所有电子秤。

收衣界面显示重量与毛/净重，店员必须在 30 秒内明确“记录到订单”。读数追加至现有订单备注，
随开单/挂单的事务与审计保存；保留原备注，超过 256 字拒绝，不截断。重量不自动改变已有按件计价。
记录具有人工可编辑备注的语义，不作为经认证称量凭证。IPC 为有限 `desktop:scale:operation`，
需有效登录，会话在读取中变更即丢弃结果；恢复只读模式不开放操作。

验证覆盖协议边界、时间与大小约束、会话失效、IPC精确清单和订单记录。Windows 串口发现与真实秤
精度、断线、稳定性须分别记录；没有实物时不得标记硬件验收完成。本轮无新增服务端业务命令/查询或表。
