# ADR-27：Owner 明细下钻与授权门店组合视图

- 日期：2026-08-08
- 状态：**Accepted**
- 决策者：manpengan
- 前序：[ADR-26：局域网只读 Owner Dashboard 与 HTTPS 边界](2026-08-07-adr-26-lan-owner-dashboard.md)
- 影响：`packages/contracts` v0.2 查询冻结面、Owner LAN 只读能力、PostgreSQL RLS

## 背景

ADR-26 只交付单店四卡与 30 日趋势。店主看到取衣、新增欠款或滞留件异常后，需要有限的
店内操作标识继续核对；同时，确实在多家门店任职的管理员需要在同一只读入口比较自己有权
管理的门店。直接返回顾客资料、接受客户端门店列表，或以组织管理员身份绕过门店 RLS，都会
把首屏摘要扩大为新的隐私和越权面。

## 决策

### 1. 只新增两条固定范围 R1 查询

新增：

- `reporting.owner_dashboard.drilldown`：输入仅为严格枚举
  `today_pickups | new_receivables | stagnant_garments`；
- `reporting.owner_portfolio.get`：输入为严格空对象。

两条查询都不接受组织、门店、日期、时区、切日时刻、分页游标或行数。它们继续要求
`accounting_read`、`offline_mode = denied`、`data_classification = internal`，且不进入 AI
工具投影。契约查询冻结面从 **23 → 25**，命令面仍为 **39**。

### 2. 明细必须与首屏同口径、同快照

明细查询在服务端当前门店与当前营业日内运行，并为所选类别返回完整汇总与最多 50 行：

- 今日取衣：按今日 `picked_up` 状态转换事件汇总件数与订单数；
- 新增欠款：只含今日新开、刷新时仍有余额的订单；
- 滞留件：只含已收满 30×24 小时、仍为 open 且衣物为 ready/racked 的订单。

汇总必须逐项等于 ADR-26 对应卡片；`truncated` 只表示明细行被截断，不能截断汇总。行只返回
店内票号、时间、件数、账龄和欠款金额等核对字段；不返回顾客 ID、姓名、手机号、订单 UUID、
条码或架位。

### 3. 组合视图逐店重新证明授权

服务端以会话组织枚举候选门店，但不得据此直接读取所有门店。候选扫描固定最多 200 家，
超过即整次失败关闭，避免只读长事务内无界逐店扫描。对每个候选门店必须在同一个
只读一致性快照内：

1. 将 `app.store_id` 切换到该候选门店；
2. 通过 RLS 重新确认当前会话员工在该店仍为 active admin；
3. 仅对授权通过的门店复用 ADR-24/26 口径计算四卡；
4. 无论成功或失败都恢复原门店 GUC。

结果最多 50 家授权门店，固定按门店编码与名称排序；总计只汇总实际返回的授权门店，超过
上限时设置 `truncated`。输出只含门店编码、名称、时区、营业日与四卡，不返回内部门店 UUID。
组织不同、同组织但未授权或已停用的门店必须不可见。

### 4. 验收

- Zod 拒绝额外字段、客户端范围与未知类别；普通员工仍为 403；响应不可缓存；
- 真实 PostgreSQL 覆盖同组织未授权店、已停用角色、跨组织、营业日切界、50 行截断及首屏与
  明细汇总一致；
- Owner Web 只从卡片进入对应明细，并提供授权门店比较；错误、空态与注销不泄露历史数据；
- LAN 网关仍只代理既有认证与通用只读查询路径，命令路径继续硬拒绝。

## 当前仍不做

- 客户资料、手机号、条码、架位、任意搜索、导出或写操作；
- 组织 owner 超级角色、跨组织访问、云端组合视图或互联网穿透；
- 客户端选择任意日期、门店、页数或排序；
- AI 经营分析、自动提醒、自动调店或远程审批。

## 后果

- ADR-26 的“后续明细/跨店须另附 ADR”由本 ADR 局部解冻；其单店首屏与 HTTPS 边界不变。
- 新增两条查询必须同步更新冻结清单、OpenAPI、CHANGELOG 与真实 PostgreSQL 验收。
- 逐店 RLS 检查优先于一次性跨店 SQL；门店规模超过当前上限时再另行设计可证明授权的分页。

## 否决的备选

- **客户端上传 store IDs**：把租户范围交给浏览器，否决。
- **组织管理员一次性绕过 store RLS**：无法证明逐店任职关系，否决。
- **复用催取名单作为滞留明细**：其手机号条件、行数和目的与 Owner 四卡不同，否决。
- **返回顾客资料方便联系**：把只读经营摘要扩大为隐私工作台，否决。
