# ADR-89：本机发起的受控远程协助

- 日期：2026-10-03
- 状态：实现与合成验证中；Windows 安装态验收独立记录
- 范围：B8；Cloud 平台继续暂停，本文不批准部署支持端或导入真实数据

## 决定

管理员在“设置 → 远程协助”阅读只读范围，勾选知情同意并重新输入当前密码后，生成最多一小时的协助会话。服务在内存中创建该次出站工作进程；数据库中的授权行本身不能启动协助。重启服务、修改支持端配置、恢复备份或跨 schema 回退后均须重新授权。

仅允许 `runtime.health`、`runtime.version`、`maintenance.summary`。结果分别是数据库可用标志、本机启动时绑定的发行版与 migration head、最近 30 天恢复维护事件次数。禁止通用 URL、文件路径、SQL、shell、顾客记录、照片、凭据或原始诊断日志；结果不持久化，只在同事务审计中保留命令、支持人员标识摘要和结果摘要。

本机只向配置的 HTTPS 443 支持端主动 POST `/v1/assistance/poll` 与 `/v1/assistance/result`。不新增入站端口。DNS 所有返回地址必须符合既有公网出站策略，并固定实际连接地址；拒绝重定向，响应最多 16 KiB，一次交换最多 10 秒。

每次轮询生成独立 256 bit nonce。支持端返回 Ed25519 JWS，精确字段绑定 issuer、audience、kid、协助 ID、nonce、唯一命令 ID、三项命令之一及人员身份。签名校验通过后仍要求最近 60 秒签发、有效期最多 60 秒、认证发生在五分钟内、`amr` 同时包含 `mfa` 与 `otp` 或 `hwk`。其他算法、动态密钥 URL、未知字段、其他会话或重复命令均拒绝。支持端和身份签发方必须提供真实的受信 MFA 证据；本项目不模拟生产身份认证。

本机每次执行前、发送结果前重新检查当前会话、刷新族、人员权限版本和管理员角色。授权、命令准备、交付回执、到期、撤销、异常中断均与审计同事务。用户撤销即时触发 AbortController 终止在途请求；已发送的字节无法撤回。墙钟和单调时钟同时约束一小时上限，防止系统时间回拨延长授权。

## 私有配置与外部条件

Windows 维护工具的“远程协助配置”通过既有 8192 字节严格 UTF-8 stdin 协议写入固定私有位置 `secrets/remote-assistance.json`。内容包括固定支持端 origin、接入令牌、issuer、audience、kid、Ed25519 SPKI 公钥。配置不进入离机业务导出或可读诊断包，读取验证私有 ACL、普通文件、单链接和文件身份。取消配置保存 null 并停止现有连接。外部支持端或可信身份配置缺失时失败关闭；普通门店功能不依赖支持端。

配套命令行支持客户端只交换外部签发的证据，不提供假 MFA 签发器，也不托管或部署 broker。独立合成测试使用一次性密钥和内存传输，不将其用作生产身份。

## 验证与限制

协议覆盖签名、issuer/audience、MFA、时效、nonce、会话、命令白名单和响应界限。服务测试覆盖默认关闭、重启不续权、撤销中的晚返回、单调时钟过期。真实 PostgreSQL 覆盖 app 角色权限、租户隔离、重复命令、权限变化、终态不可复活和审计失败整事务回滚。GUI、IPC 和离线恢复模式有独立负向测试。

Windows 原生配置、打包版 GUI 与安装态出站验收须另行记录，静态审查或 Mac 测试不替代这些门禁。
