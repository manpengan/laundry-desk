# ADR-76：Windows 一键脱敏诊断导出

状态：Proposed，依据用户授权实施，Windows 实机验收另记。

## 决策

在 ADR-72 的 A8 范围内，Windows 本地服务维护窗口新增“导出诊断”，
对应固定 `diagnostics` 动作。它在现有发布摘要校验、私有目录检查与维护锁内运行，
不改变运行状态，不恢复 pending upgrade，不启动或停止数据库。

诊断文件是最大 256 KiB 的 UTF-8 JSON：固定版本/源码/迁移摘要、服务端口与后台任务是否存在、
维护阶段、备份元数据有效/不完整数量及空间摘要。失败的采集分区明确标记 `unavailable`，
不把“端口存在”表述为业务健康、不把元数据有效表述为备份已通过恢复校验。
维护中断与部分初始化时仍可导出；无有效安装状态时继续失败关闭。

文件使用生成的 UUID 名称、私有 ACL、独占创建、落盘同步；同目录最多 32 份，
达到上限给出明确错误，由操作人移出已有文件后再导出，不自动删除用户文件。
返回文件位置、SHA-256 与字节数，维护窗口直接显示，可由操作人选择分享。

## 理由

已有跨平台支持包依赖源码 checkout/Compose 且不支持安装后的 Windows Runtime。
独立维护入口必须在服务故障时可用，因此使用本机有限只读采集，避免依赖应用登录与可用数据库。
采用字段白名单；顾客资料、照片、数据库行、原始日志、主机名、账号名、环境变量、凭据一律不读不导出。
诊断 JSON 内不含本机路径；路径只在本机界面回执显示。打印诊断按用户决定暂缓。

## 否决的备选

- 对任意日志做正则替换：无法证明已去除所有顾客资料与供应商凭据。
- 上传服务器或打开远程 shell：超出本功能边界，亦不符合 Cloud 暂停范围。
- 维护动作失败后自动重启：诊断不应改变待调查现场。

## 后果

新增本机维护动作，没有新增业务 Command/Query 或公网端点。
行为回归覆盖私有输出、哈希、错误不泄露、坏备份计数、保留上限、链接/额外文件拒绝；
Windows 构建和安装包需验证真实 DACL、PowerShell 5.1 解析与维护窗口按钮。
不包含原始堆栈或日志正文会减少诊断细节，这是有意的最小化边界。
