   Runtime 入口绑定与迁移摘要。安装在明确标识的合成环境，不覆盖其他 QA 或真实服务。
3. 使用两个独立管理员及普通店员，验证新建价目、客户、按件照片、开单、挂单、取衣、补缴/退款、
   交班、订单历史和对账；记录整数分与件数不变量。外部渠道只用明确标识的夹具。
4. 注入断连、迟到响应、首个响应丢失、会话过期、服务端已提交后强杀、恢复文件不可读和空间不足。
   核对原操作恢复、同键重试、无重复订单/收款，恢复失败时持续提示，不能转为新开单。
5. 从已安装维护 GUI 执行立即备份、验证、影子演练、定时计划与留存；覆盖停机时错过计划、磁盘不足、
   权限拒绝、备份损坏和维护中断。核对失败可见、原现场保留、责任人确实收到并处理提示。
6. 将加密数据库/照片副本写入指定独立介质。第二台机器和另一 Windows 用户创建独立可信实例，
   使用维护入口恢复并核对金额、计数、照片摘要、权限撤销、旧会话失效和供应商配置需重新授权。
   从宣布故障开始计时，包含找介质、取得口令、安装、恢复、核对和重新批准写入。
7. 用合成 v1 只读 checkpoint 副本完成迁移预览、照片批量匹配、差异排除、批准、一次性导入与对账。
   正式迁移素材须另获授权；不因本步骤通过而读取门店 live SQLite。
8. 完成实际目标 Windows 10/11、100%/150%/200% DPI、中文 IME、短窗口、浅深色、键盘/焦点、
   原生关闭、第二实例、注销/登录、OS 重启与卸载重装保留状态矩阵。不可用环境标为未执行。
9. 请普通店长独立完成维护 GUI 任务，记录是否需要命令行/抄写标识、失败原因及完成时间。
   由辅助技术使用者验证关键业务路径；没有实际参与者时保留缺口，不以脚本代替。
10. 汇总证据、未满足项与 RPO/RTO 等待决策字段，提交 manpengan 审阅 ADR-98；验收阶段不自动切生产。

## 获准后的切换清单

本节为待签署的操作方案，不表示已获准执行。

1. 核对 ADR-98 的签署、机器、人员、能力范围与候选 SHA；两位管理员确认真实资料导入的具体授权。
2. 冻结 v1 写入窗口，由数据责任人提供获授权 checkpoint 副本及照片归档；记录只读来源摘要。
3. 先备份目标实例及照片并验证可恢复。运行 dry-run，核对订单/件数、整数分账目、会员余额与照片引用，
   任何未解释差异保持停止。旧密码不迁移，旧员工资料按既有保全规则处理。
4. 经第二位管理员核对后，使用既有一次性批准及受信维护入口导入；禁止直接 SQL 或覆盖 live SQLite。
5. 验证普通店员权限、每个已启用外部渠道、定时任务、离机副本及故障响应。未启用能力保持关闭。
6. 数据责任人与独立管理员记录初始核对结果并批准开放写入；开始约定的受控试点，原 v1 保持只读。

## 日常运行与异常停止

- 开店：检查服务、同步/待确认操作、上次备份与演练、离机副本和空间状态。任一状态未知先核查。
- 营业：未知付款先查原意向与商户结果；未知开单使用原操作确认。顾客切换、失败列表或旧票据不能作为收款成功证明。
- 闭店：两人核对订单数、件数、应收/实收/退款/欠款、会员账本、对账待复核项和已启用渠道回执；
  执行约定备份及介质轮换。记录计数、摘要、时间和固定错误码，避免记录顾客姓名、手机号或照片。
- 事故：达到签署的停止条件即停写，保存原始备份、维护日志和未确认操作；联系数据责任人与接替人。
  维护状态不明时禁止重新初始化、删日志或“清空后再试”。

## 回退与恢复营业

1. 停止业务写入和外部派发，记录最后已确认交易时间。先保存当前数据库及照片安全点。
2. 从可信维护 GUI 查看阶段。中断维护只使用“继续中断维护”；摘要/OID 不匹配时保留现场并停止。
3. 程序回退选择对应发行对。跨结构回退必须同时选绑定的旧数据快照，不能只替换 EXE 或数据库目录。
4. 将回退后的业务快照与回退前安全点逐项核对。新结构阶段发生的业务写入不会自动并入旧结构，
   必须由数据责任人制定对账补录方案；保留安全点直至确认处理完成。
5. 查明支付、退款、短信等外部结果，恢复数据库不能撤销这些动作，不自动重发未知交易。
6. 重新验证权限、备份、离机恢复点与业务闭环，由两位获授权人员记录核对并单独批准恢复营业。

## 证据归档要求

每份证据记录：测试 ID、源码/安装组合、机器/OS、开始结束时间、合成数据标识、动作、预期、实际结果、
日志/截图路径与 SHA-256、复核人。失败、跳过和阻挡保留原文，不从后续通过推定早期失败已通过。
不得收集口令、PIN、token、连接串、密钥、顾客资料、票据正文或照片进入公共报告与 CI artifact。
诊断仅使用受限诊断导出；真实资料的加密备份由具名保管人保管，与可公开的验证证据分离。
