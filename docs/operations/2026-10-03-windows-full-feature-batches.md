## 依赖与分工

- 首批并行实现 A1、A5、A7。各自完成可用的纵向功能和回归，不只新增接口或模拟器。
- A1–A4 共享 Windows 维护锁、状态机与恢复记录，由同一责任人接续；A5/A9 复用其照片端口。
- A7 后接 B5/B6；B1/B2 后接顾客自助写面与 B4。B3 与业务账本、幂等和审计共同集成。
- root 负责共享注册表、契约协调、公共文档、锁文件、独立审查、分批提交推送和最终集成。
- 并行工作者不自行提交，不回退其他人的更改。迁移 `0070_windows_v1_import.sql` 预留给 A5；
  后续迁移编号由 root 串行分配。ADR-73/74/75 分别预留 A1/A5/A7。
