## 根因：柜台与本地服务对安装位置的理解不一致

本地服务安装程序按 [ADR-69](../../adr/2026-10-01-adr-69-windows-runtime-operator-entry.md) 把入口装在
`%LOCALAPPDATA%\Programs\Laundry Desk Runtime V2\<manifest>`（读 `LOCALAPPDATA` 变量）。
柜台的维护引导脚本却用 `[Environment]::GetFolderPath('LocalApplicationData')`（系统“已知文件夹”）查找。
已知文件夹 API 不看 `LOCALAPPDATA` 变量。验收为隔离把 `LOCALAPPDATA` 指向合成目录，两者分开，
柜台找不到已装好的本地服务，于是报连接失败。普通门店电脑上两者通常是同一目录。

在 winbox 上用与验收柜台相同的环境（Session 1 普通令牌、同样的变量、同样的固定信任脚本和入口摘要）
直接重放柜台的这次调用，只做只读 `health`：

| 引导脚本                    | 结果                                                                                                                                   |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 原脚本（已知文件夹）        | 已知文件夹解析为真实用户目录，入口不在那里；0.5 秒退出码 1，stderr 为 `WINDOWS_RUNTIME_ENTRY_FAILED`                                   |
| 改读 `$env:LOCALAPPDATA` 后 | 13.7 秒返回完整 `backup_health`，退出码 0，stderr 为空；提醒为 `task_missing`、`offsite_overdue`（收尾已删除测试计划任务、无离机副本） |

修复见 [PR #245](https://github.com/manpengan/laundry-desk/pull/245)：引导脚本改读 `$env:LOCALAPPDATA`，
沿用安装程序的盘符根路径检查；目录持有、私有目录断言、入口大小与摘要固定校验不变。
本候选 `5db094aa` 的维护程序 GUI 因此不能记为通过，后续取衣、经营、补充、备份负例与 U07 专项按顺序需要主流程先通过，
在本候选上未执行；改为在包含修复的新候选上完整复跑（下节）。

因此锁屏不妨碍发现窗口；维护主窗口未就绪的原因仍未确认。诊断 v4 已准备记录窗口实际内容
（最后一次界面快照与该进程全部顶层窗口的标题、可用状态和文字），本记录尚未取得其执行终态。

## 方法

验收沿用 Codex 为前一候选 `9719af1b` 冻结的脚本，只做机械换绑：

1. 把源码 SHA、根目录、短标识和 Runtime 版本号逐字替换为本候选的值。
2. 脚本之间互相固定的 SHA-256 按依赖关系重算，直到收敛。
3. 每个文件反向替换后必须与原脚本逐字节相同，`.mjs`/`.cjs` 通过 `node --check`，`.ps1` 在 Windows PowerShell 5 解析无误。
4. 构建产出的固定值（Runtime manifest、入口、原生 helper、双 profile 的 EXE/ASAR/helper/配置/来源、安装回执）在本候选构建和安装后，从实际回执重新取值换绑。

换绑中发现并修正一处遗漏：`native-exit-token-start-shared-v2.ps1` 内嵌的
PowerShell `-EncodedCommand`（UTF-16LE Base64）仍指向前一候选目录和旧探针摘要。
文本替换看不到编码内容；修正后解码、换绑、再编码，并对解码内容做同样的残留检查。该文件在修正前没有执行过。

前一候选 `offline-binding.mjs` 固定的 SPA `d22fd188…` 与该候选自己的 SPA `f2eeb3ee…` 并不相同，
说明这个固定值在前一候选就已过期（该轮补充验收未运行到这一步）。本候选按 runner 的计算方式
（manifest 字节的 SHA-256）换绑为 `00737795…`，并由安装树预检独立复核。

## 范围与仍欠

- Runtime 仍是 `development_only`；安装由管理员令牌辅助，不等于普通店长独立安装。
- 只在 DESKTOP-MAN（Windows 10 家庭中文版 19045）执行；Windows 11、多种 DPI、中文输入法、门店同级电脑和真人走查仍按[门店走查清单](store-walkthrough.md)另行取得。
- 没有替换原有常驻开发服务；每轮结束后核对其恢复。
- ADR-98 仍未签署；真实渠道、跨机跨 SID 恢复等外部条件见[准入手册](../project-remediation-20261006/local-admission.md)。
