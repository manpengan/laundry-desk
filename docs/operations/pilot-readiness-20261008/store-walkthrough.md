## A. 流畅度（ADR-99，约 15 分钟）

1. **客观测量。** 打开“设置 → 外观与快捷键”，在“动效”行点“检测流畅度”，等 3 秒，把结果抄下来。软件会临时用“标准”档测量，结束后还原原来的档位。
   - 通过：平均 ≥ 55 帧/秒且慢帧 ≤ 5%（软件显示“流畅”）。
   - 显示“略有卡顿”或“明显卡顿”时，这台电脑应使用“节能”，点结果旁的“改用节能”即可。
2. **动效档位显示什么。** 记下“动效”默认的“自动”下面那行说明：写的是“显卡加速可用”还是“已改用节能”。
3. **页面切换。** 在“标准”档下，从侧栏依次点每个页面，来回两遍。
   - 第二遍起应无明显停顿。第一次打开某页时轻微停顿属于正常（页面首次加载）。
   - 侧栏亮起的玻璃块应顺滑滑到点中的页面。
4. **连点按钮。** 在工作台快速连点“进入取衣”或任一蓝色主按钮 10 次（输入框留空即可）。每次都应有按下回弹和水波，界面不卡住。
5. **列表滚动。** 在“订单”或“设置”页用滚轮快速上下滚动 10 秒。顶栏下方出现柔和阴影，画面跟手、无撕裂。
6. **主题切换。** 在“外观”里依次点 6 套配色，再切换浅色、深色。
   - 每次点击后约半秒内整页换色，不出现“点了没反应”。
   - 深色主题下关闭柜台再打开，启动时不应先闪一下浅色底。
7. **节能与关闭。** 切到“节能”：背景停止流动，按压与切换反馈保留。切到“关闭”：没有任何动画。最后改回你决定的档位。

| 步骤               | 结果（通过 / 不通过 + 现象） |
| ------------------ | ---------------------------- |
| 1 检测流畅度数字   |                              |
| 2 自动档说明       |                              |
| 3 页面切换         |                              |
| 4 连点按钮         |                              |
| 5 列表滚动         |                              |
| 6 主题切换与启动   |                              |
| 7 节能与关闭       |                              |
| 结论：本机使用档位 |                              |

不达标时，先把“自动”的判定收紧到节能（ADR-99），不回退设计；记录现象和机器型号，交给开发处理。

## B. 普通店长真人走查（ADR-98 运营闭环，约 45 分钟）

由**没参与开发**的店长独立操作，旁观者只记录、不提示。每项记下是否独立完成、用时、卡在哪里。

## C. 恢复与容量实测（约 30 分钟）

只在测试实例上做，不碰将来要用的生产实例。

1. 记下 B10 那次备份的大小和耗时（备份结果里有时间）。
2. 在维护程序里执行一次**恢复演练**并计时。演练只读影子库，不影响营业。
3. 如已授权：在测试实例上做一次**完整恢复**，计时到“能登录并查到 B2 订单”。这个时长就是本机 RTO 的实测值。
4. 有第二台电脑时，用离机介质在另一个 Windows 用户下恢复一次并计时，作为换机 RTO 的实测值。

| 项目                    | 实测 |
| ----------------------- | ---- |
| 备份大小 / 耗时         |      |
| 恢复演练耗时            |      |
| 本机完整恢复耗时（RTO） |      |
| 换机、换用户恢复耗时    |      |

把实测值填回[决策工作表](decision-worksheet.md)第 3 节，再确认 RPO/RTO 是否采用建议值。
