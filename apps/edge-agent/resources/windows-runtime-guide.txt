Laundry Desk V2 Windows 开发版安装说明

1. 解压同批次 Runtime 安装与维护包，双击 Laundry Runtime V2.cmd。
2. 首次使用选择“安装本地服务”，等待成功后选择“查看状态”。
3. 安装柜台 EXE，再从桌面或开始菜单启动柜台。柜台连接本机服务。
4. 维护入口安装后在开始菜单中保留。卸载柜台不会删除服务、数据库或备份。

维护前先退出柜台。入口提供状态、启停、修复、升级、程序回滚和备份操作。
升级使用新批次入口并选择“升级到本包”；程序回滚沿用原有数据库，不是数据恢复。
恢复数据时先查看备份、明确选择一份，并人工输入所选备份的完整确认摘要。
恢复会先创建安全点。维护中断时先查看状态，再明确选择“继续中断维护”。
